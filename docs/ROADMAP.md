# Qualification roadmap

Completed software milestone: journal discovery, retrieval, structured automatic contribution links, daily notice workflow, source evidence retention, editorial decisions, offline end-to-end tests and local launch instructions.

Remaining research and production gates:

1. Expand automatic evidence adapters for included-study tables, supplements, rotated/scanned pages, forest plots and DOI-less reports. Preserve study/report/effect distinctions and source conflicts.
2. Establish an independently adjudicated reference standard on full reviews and supplements. Development annotations must not become routine author or editor data-entry requirements.
3. Hold out entire reviews across publishers and layouts. Measure report-level contribution precision/recall, abstention, DOI-resolution accuracy, eligible-review discovery recall, end-to-end journal coverage and retraction-case precision. Report denominators and confidence intervals; abstentions are not true negatives.
4. Choose and document acceptance thresholds before evaluating a held-out set. Qualify or reject any local model for its actual role. Exact quotes and valid JSON are not evidence of scientific accuracy.
5. Validate real review–contributing-report–retraction cases, changed content, reinstatement conflicts, backup/restore, disk failure and interrupted jobs.
6. Run at least seven daily cycles on the target 8GB Mac, measuring peak memory, duration, source failures, deferred work and missed schedules. Size request budgets to the actual journal.
7. Complete editorial usability evaluation and release review. Only then claim production readiness or plan a shared hosted deployment.

There is no paid-service dependency in this plan. Higher-capacity optional local models must be tested within the available hardware rather than assumed to solve extraction.
